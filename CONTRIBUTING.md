# Contributing

This is a maintainer-led personal academic homepage, not a general-purpose collaborative publication database. We are not soliciting unsolicited code pull requests. The pull request template exists for maintainers and explicitly invited collaborators; a green Community Standards checkmark does not imply that external changes will be accepted.

Factual corrections and reproducible website bugs are welcome. If repository Issues are enabled, use the relevant issue template. Otherwise, use the Email control on the [homepage](https://zhixiang-ren.github.io/). Do not put private information, unpublished work, or security details in a public issue. Report vulnerabilities as described in [`SECURITY.md`](./SECURITY.md).

For an invited change:

1. Read [`README.md`](./README.md), [`AGENTS.md`](./AGENTS.md), and [`CONTENT-NOTICE.md`](./CONTENT-NOTICE.md).
2. Keep English and Chinese content synchronized, and verify academic facts against authoritative sources.
3. Make the smallest scoped change; do not substitute personal identity, portrait, or protected prose with template content.
4. Run `npm run build` and check the affected page in both languages and relevant screen sizes.
5. Summarize the change, evidence, and verification in the pull request template.

Only submit code and assets you have the right to contribute. Reusable software is MIT-licensed, but the person's identity, portrait, and original site content are not. See the [license](./LICENSE) and [content notice](./CONTENT-NOTICE.md) for the boundary.
