# Community conduct

This repository is the source for a personal academic website. Discussions about the website, its reusable code, and factual corrections should remain respectful, specific, and professional.

- Discuss ideas and defects without personal attacks, harassment, discrimination, or intimidation.
- Respect the subject's and contributors' privacy. Do not publish private contact details, unpublished research, credentials, or other confidential material.
- Attribute others' work accurately and distinguish verified publication facts from speculation.
- Accept that the site owner decides which changes belong on this personal homepage.

These expectations apply to repository issues, pull requests, reviews, and other project discussions. Maintainers may edit, hide, lock, or close material that violates them, using GitHub's moderation tools. To report abusive behavior, use GitHub's **Report content** controls; do not post sensitive evidence publicly. For a security vulnerability, follow [`SECURITY.md`](./SECURITY.md) instead.
